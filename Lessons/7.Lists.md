# Lesson 7: Lists - Working with Collections of Data

Lists are one of the most important data structures in Prolog. This lesson teaches you how to work with them.

---

## 📋 What Is a List?

A **list** is a collection of items in order, like a to-do list or a shopping list.

**In Prolog, a list looks like:**
```prolog
[apple, banana, orange]
[1, 2, 3, 4, 5]
[tom, bob, liz]
[john, mary, [alice, bob]]
[]
```

**Key points:**
- Items are separated by commas `,`
- Enclosed in square brackets `[` and `]`
- An empty list is `[]`
- Lists can contain numbers, atoms (words), or even other lists

---

## 🏗️ The Structure of a List: Head and Tail

Every non-empty list has two parts:

**Head:** The first element
**Tail:** Everything after the first element (also a list)

**Visual:**
```
[apple, banana, orange]
 ^^^^^
 head = apple

[apple, banana, orange]
        ^^^^^^^^^^^^^^^^
        tail = [banana, orange]

[apple]
 ^^^^^
 head = apple
 
[apple]
        
 tail = []
```

### The Pipe Notation: `|`

We use the `|` symbol to separate head and tail:

```prolog
[H|T]
```

This means:
- `H` is the head (first element)
- `T` is the tail (rest of the list)

**Examples:**
```prolog
[apple, banana, orange] = [H|T]
% H = apple
% T = [banana, orange]

[1, 2, 3] = [H|T]
% H = 1
% T = [2, 3]

[john] = [H|T]
% H = john
% T = []

[] = [H|T]
% NO UNIFICATION! Empty list has no head or tail
```

## 🔍 Pattern Matching with Lists

Lists are matched the same way as other Prolog structures - through unification.

### Example 1: Extract First Element

```prolog
?- [apple, banana, orange] = [H|T].
```

**Unification:**
```
[apple, banana, orange] = [H|T]
H = apple
T = [banana, orange]
```

**Result:**
```
H = apple,
T = [banana, orange].
```

### Example 2: Extract First Two Elements

```prolog
?- [apple, banana, orange, grape] = [H1, H2|T].
```

**Unification:**
```
[apple, banana, orange, grape] = [H1, H2|T]
H1 = apple
H2 = banana
T = [orange, grape]
```

**Result:**
```
H1 = apple,
H2 = banana,
T = [orange, grape].
```

### Example 3: Match a List Pattern

```prolog
?- [1, 2, 3] = [1, 2|T].
```

**Unification:**
```
[1, 2, 3] = [1, 2|T]
1 = 1 ✓
2 = 2 ✓
T = [3]
```

**Result:**
```
T = [3].
```

### Example 4: Check if Specific List

```prolog
?- [1, 2, 3] = [1, 2, 3].
```

**Result:**
```
true.
```

## 📝 Lists in Facts and Rules

### Fact: A List of Students

```prolog
students([alice, bob, charlie, diana]).
```

This says: "The list of students is [alice, bob, charlie, diana]"

### Query 1: Who are the students?

```prolog
?- students(X).
```

**Result:**
```
X = [alice, bob, charlie, diana].
```

### Query 2: Extract the first student

```prolog
?- students([First|Rest]).
```

**Result:**
```
First = alice,
Rest = [bob, charlie, diana].
```

## 🎯 Practical List Rules

### Rule: Check if Something is in a List

**File: list_operations.pl**

```prolog
% member(X, List) is true if X is in List
member(X, [X|_]).                    % X is the head
member(X, [_|T]) :- member(X, T).    % Or X is in the tail
```

**Explanation:**
- First rule: X is a member if it's the first element of the list
- Second rule: X is a member if it's a member of the rest of the list (recursive!)

**Testing:**
```prolog
?- member(bob, [alice, bob, charlie]).
```

**Result:** `true.`

**How Prolog reasons:**
```
1. Is bob the head of [alice, bob, charlie]? NO
2. Is bob a member of [bob, charlie]? 
   - Is bob the head of [bob, charlie]? YES!
   - Result: true
```

### Rule: Find the Length of a List

```prolog
% length(List, N) is true if List has N elements
length([], 0).                            % Base case: empty list
length([_|T], N) :- length(T, N1), N is N1 + 1.  % Recursive case
```

**Testing:**
```prolog
?- length([a, b, c], N).
```

**Result:** `N = 3.`

### Rule: Append Two Lists

```prolog
% append(List1, List2, List3) is true if 
% List3 is List1 followed by List2
append([], L, L).                    % Base case
append([H|T], L, [H|R]) :- append(T, L, R).  % Recursive case
```

**Testing:**
```prolog
?- append([1, 2], [3, 4], X).
```

**Result:** `X = [1, 2, 3, 4].`

## 🧪 Common List Operations

### Create a List
```prolog
?- X = [1, 2, 3].
% X = [1, 2, 3]
```

### Check First Element
```prolog

```

```prolog

```

### Check Length (if you have length/2 rule)

```prolog
% N = 3

```


## 🌳 Recursive List Processing

Many list operations are **recursive** - they process one element at a time.

### Example: Sum All Numbers in a List

```prolog
sum_list([], 0).                         % Base case: empty list sums to 0
sum_list([H|T], Sum) :-                  % Recursive case
    sum_list(T, TSum),                   % Sum the rest
    Sum is H + TSum.                     % Add the head to that sum
```

**Testing:**
```prolog
?- sum_list([1, 2, 3, 4], Sum).
% Sum = 10
```

**How it works:**
```
sum_list([1, 2, 3, 4], Sum)
  H=1, T=[2,3,4]
  sum_list([2,3,4], TSum)
    H=2, T=[3,4]
    sum_list([3,4], TSum2)
      H=3, T=[4]
      sum_list([4], TSum3)
        H=4, T=[]
        sum_list([], TSum4)
          TSum4 = 0
        Sum3 = 4 + 0 = 4
      Sum2 = 3 + 4 = 7
    Sum = 2 + 7 = 9
  Sum = 1 + 9 = 10
```

## 🚨 Common List Mistakes

### Mistake 1: Forgetting the Brackets

```prolog
% WRONG
X = apple, banana, orange

% RIGHT
X = [apple, banana, orange]
```

### Mistake 2: Using Semicolon Instead of Comma

```prolog
% WRONG
[apple; banana; orange]

% RIGHT
[apple, banana, orange]
```

### Mistake 3: Confusing Head and Tail Syntax

```prolog
% WRONG
[apple, banana, orange] = [H, T]
% This would make H=apple, T=banana (wrong!)

% RIGHT
[apple, banana, orange] = [H|T]
% This makes H=apple, T=[banana, orange]
```

### Mistake 4: Forgetting the Pipe in Pattern

```prolog
% WRONG - trying to pattern match [H|T]
member(X, [X]).  % This only matches 1-element lists!

% RIGHT
member(X, [X|_]).  % X is the head, we don't care about the tail
```

## 📚 Built-in List Predicates

Prolog has built-in predicates for common list operations. Here are the most useful:

```prolog
length([1,2,3], N).           % N = 3
append([1,2], [3,4], X).      % X = [1,2,3,4]
member(2, [1,2,3]).           % true
reverse([1,2,3], X).          % X = [3,2,1]
nth0(1, [a,b,c], X).          % X = b (0-indexed)
nth1(2, [a,b,c], X).          % X = b (1-indexed)
last([1,2,3], X).             % X = 3
sort([3,1,2], X).             % X = [1,2,3]
```

You can use these directly - Prolog has them built-in!

## 🎯 Practice Problems

### Problem 1: Find Second Element
Create a rule that gets the second element of a list.

**Answer:**
```prolog
second([_, Second|_], Second).
```

**Test:**
```prolog
?- second([a, b, c, d], X).
% X = b
```

### Problem 2: Check if List is Empty
Create a rule that checks if a list is empty.

**Answer:**
```prolog
is_empty([]).
```

**Test:**
```prolog
?- is_empty([]).         % true
?- is_empty([a]).        % false
```

### Problem 3: Count Elements
Create a rule that counts how many elements in a list.

**Answer:**
```prolog
count([], 0).
count([_|T], N) :- count(T, N1), N is N1 + 1.
```

**Test:**
```prolog
?- count([a, b, c], N).
% N = 3
```

## 💡 Summary

**Lists in Prolog:**
- Written as `[item1, item2, item3]`
- Have a head (first element) and tail (rest)
- Use `[H|T]` syntax to separate head and tail
- Are processed recursively
- Many operations (member, append, length) can be written as rules

**Lists are fundamental to Prolog** - you'll use them constantly in real programs!
