# Lesson 5: Queries - Asking Questions

Now you know how to write facts and rules. This lesson teaches you how to ask Prolog questions in different ways.

---

## ❓ What Is a Query?

A **query** is a question you ask Prolog. It's how you make Prolog think and find answers.

**Symbol:** The `?-` prompt in the Prolog interpreter

**Basic structure:**
```prolog
?- something_you_want_to_prove.
```

## 🔍 Types of Queries

### Type 1: Yes/No Questions

**Ask:** "Is this statement true or false?"

```prolog
?- parent(tom, bob).
```

**Answer:** `true.`

**Another example:**
```prolog
?- parent(tom, alice).
```

**Answer:** `false.`

Prolog checks the database. If it finds a matching fact, it says `true`. If not, it says `false`.

**More examples:**
```prolog
?- grandparent(tom, ann).     % true
?- grandparent(bob, bob).     % false (not a grandparent of yourself)
?- sibling(bob, liz).         % true
?- sibling(tom, bob).         % false (parent-child, not siblings)
```

### Type 2: Find Something (Single Variable)

**Ask:** "Who is X?" or "What is X?"

```prolog
?- parent(tom, X).
```

**Answer:**
```
X = bob
```

Prolog finds the first match and stops.

**To see more answers:**
Press `;` (semicolon) and Enter to see the next answer:

```
X = bob ;
```

Press `;` again:
```
X = liz
```

Press `;` again:
```
false
```

No more answers.

**Or just press `.` (period) to stop looking for more answers.**

### Type 3: Find Multiple Things

**Ask:** "What's the relationship between X and Y?"

```prolog
?- parent(X, Y).
```

**Answers (press `;` between each):**
```
X = tom, Y = bob ;
X = tom, Y = liz ;
X = bob, Y = ann ;
X = bob, Y = pat ;
X = pat, Y = jim ;
false
```

Each answer shows one parent-child pair.

### Type 4: Count Things

**Ask:** "How many answers are there?"

```prolog
?- parent(X, Y).
```

This doesn't automatically count, but you press `;` and count:
- tom-bob ✓
- tom-liz ✓
- bob-ann ✓
- bob-pat ✓
- pat-jim ✓

Total: 5 parent-child pairs.

### Type 5: Complex Conditions

**Ask:** "Find X that satisfies multiple conditions"

```prolog
?- parent(tom, X), parent(X, Y).
```

**Answer:**
```
X = bob, Y = ann ;
X = bob, Y = pat ;
false
```

**What does this mean?**
"Find X such that tom is parent of X AND X is parent of Y"

This is asking: "Who are Tom's children's children?"
- X = bob (Tom's child)
- Y = ann or pat (Bob's children)

## 🧠 How Prolog Evaluates Queries

Let's trace through a query step by step.

**Query:** `?- parent(tom, X), parent(X, Y).`

**Prolog's thinking:**
```
1. First goal: parent(tom, X)
   Search facts for parent(tom, ?)
   Found: parent(tom, bob) ✓
   So X = bob

2. Second goal: parent(X, Y) where X = bob
   Search facts for parent(bob, ?)
   Found: parent(bob, ann) ✓
   So Y = ann
   
3. Both goals satisfied!
   Answer: X = bob, Y = ann ✓

4. User presses `;` for more answers
   Continue from parent(bob, ?)
   Found: parent(bob, pat) ✓
   So Y = pat
   
5. Both goals satisfied again!
   Answer: X = bob, Y = pat ✓

6. User presses `;` for more answers
   No more parent(bob, ?) matches
   Try different X values
   parent(tom, liz) - but parent(liz, Y) has no matches
   No solution

7. Done! Answer: false
```

## 🎨 Query Patterns

### Pattern 1: Checking a Fact

```prolog
?- parent(tom, bob).
% Is Tom a parent of Bob? YES/NO

?- sibling(bob, liz).
% Are Bob and Liz siblings? YES/NO
```

### Pattern 2: Finding Direct Children

```prolog
?- parent(tom, X).
% Who are Tom's children?
% Answer: bob, liz

?- parent(X, ann).
% Who is Ann's parent?
% Answer: bob
```

### Pattern 3: Chaining Relationships

```prolog
?- parent(tom, X), parent(X, Y).
% Find Tom's grandchildren (children's children)
% Answer: X=bob, Y=ann or X=bob, Y=pat

?- ancestor(tom, X), ancestor(X, jim).
% Who is between Tom and Jim in the family tree?
% Answer: X=bob, pat
```

### Pattern 4: Using Rules in Queries

```prolog
?- grandparent(tom, X).
% Prolog uses the grandparent rule to find answers!
% Answer: ann, pat

?- sibling(X, liz).
% Who is a sibling of Liz?
% Answer: bob
```

---

## 📋 Special Symbols in Queries

### Comma (,) - AND

```prolog
?- parent(tom, X), parent(X, Y).
% Both conditions must be true
```

### Semicolon (;) - OR (Advanced)

```prolog
?- parent(tom, X) ; parent(bob, X).
% Find X that is either Tom's child OR Bob's child
```

### Underscore (_) - I Don't Care

```prolog
?- parent(tom, _).
% Is Tom a parent of anyone?
% Answer: true (we don't need the name)
```

### \= - Not Equal

```prolog
?- parent(X, Y), X \= Y.
% Find all parent-child pairs where parent ≠ child
% (Obviously always true, but shows the operator)
```

## 🎯 Practical Query Examples

### Example 1: Who Are All of Tom's Descendants?

```prolog
?- ancestor(tom, X).
```

**Answer:**
```
X = bob ;
X = liz ;
X = ann ;
X = pat ;
X = jim ;
false
```

Everyone descended from Tom!

### Example 2: Is There Anyone Without a Parent (in our database)?

```prolog
?- \+ parent(X, _), parent(_, X).
```

Wait, this uses `\+` (NOT) which we haven't learned. Let's skip this for now.

### Example 3: What's the Relationship Between Tom and Ann?

```prolog
?- parent(tom, ann).         % false
?- grandparent(tom, ann).    % true
?- ancestor(tom, ann).       % true
```

Try different relationships until one is true!

## 🚨 Common Query Mistakes

### Mistake 1: Forgetting the Period
```prolog
?- parent(tom, X)
% Missing period! Won't work
```

**Fix:**
```prolog
?- parent(tom, X).
```

### Mistake 2: Using Lowercase for Variables
```prolog
?- parent(tom, x).
% This looks for the fact parent(tom, x), not a variable!
```

**Fix:**
```prolog
?- parent(tom, X).
```

### Mistake 3: Forgetting the ?-
```prolog
parent(tom, X).
% This looks like a fact, not a query!
```

**Fix:**
```prolog
?- parent(tom, X).
```

---

## 💡 The Query Workflow

```
1. Write query: ?- something.
2. Press Enter
3. Get first answer
4. Press ; for more OR . to stop
5. Prolog searches through all matching facts/rules
6. Shows all possible answers
```
