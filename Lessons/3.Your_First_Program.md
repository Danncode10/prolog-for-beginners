# Lesson 3: Your First Prolog Program - Hello World Explained

Now that you understand *what* Prolog is, let's write your first program and break down every single character.

---

## 📝 The Program

Open your text editor (VS Code, Sublime, Notepad, etc.) and create a new file.

**Type this exactly:**
```prolog
% This is a comment - it starts with %
hello :- write('Hello, World!'), nl.
```

**Save it as:** `hello.pl` on your Desktop

Now let's break down what each part means.

---

## 🔍 Breaking Down the Program Line by Line

### Line 1: The Comment
```prolog
% This is a comment - it starts with %
```

**What is this?**
A **comment** is a note for humans. The computer ignores everything after `%` on that line.

**Why use comments?**
To explain what your code does. It's like writing notes in the margin of a book.

**Example comments:**
```prolog
% This rule checks if someone is a parent
% Calculate the total price
% Database of animals
```

### Line 2: The Rule
```prolog
hello :- write('Hello, World!'), nl.
```

Let's break this down piece by piece:

#### Part 1: `hello`
```prolog
hello :- ...
```

- `hello` is the **name of the rule**
- Think of it like naming a function in other languages
- It's a simple name with no spaces or capital letters
- Later, we'll ask Prolog to do `hello` and it will execute this rule

#### Part 2: `:-`
```prolog
... :- ...
```

- This means **"IF"** or **"is defined as"**
- Think of it as "the recipe for how to make hello happen"
- The left side is what we want to do
- The right side is how we do it

#### Part 3: `write('Hello, World!')`
```prolog
... write('Hello, World!') ...
```

- `write()` is a **built-in function** that prints text to the screen
- `'Hello, World!'` is the text to print
- The single quotes `'...'` tell Prolog "this is text"

**What does this do?**
When we run `hello`, it prints the text `Hello, World!` to the screen.

#### Part 4: `,` (Comma)
```prolog
write('Hello, World!'), nl.
```

- The comma `,` means **"AND"**
- "Do this FIRST, then AND do this NEXT"
- So: Print the text, AND THEN do the next thing

#### Part 5: `nl`
```prolog
... nl.
```

- `nl` stands for **"new line"**
- It moves the cursor to a new line (like pressing Enter)
- Without it, the next thing printed would be on the same line

#### Part 6: `.` (Period)
```prolog
hello :- write('Hello, World!'), nl.
```

- The period `.` means **"end of statement"**
- Every rule in Prolog ends with a period
- It's like the period at the end of a sentence

---

## 🎬 Running Your Program

### Step 1: Open Terminal/Command Prompt

Navigate to your Desktop:
- **Mac:** `cd ~/Desktop`
- **Windows:** `cd Desktop`

### Step 2: Start Prolog

```bash
swipl
```

You should see:
```
?-
```

### Step 3: Load Your File

```prolog
?- consult('hello.pl').
```

You should see:
```
true.
```

This means "I successfully loaded your file." Good!

### Step 4: Run Your Program

```prolog
?- hello.
```

You should see:
```
Hello, World!
true.
```

**Congratulations!** Your first program worked! 🎉

The `true.` at the end means "the query succeeded."

### Step 5: Exit

```prolog
?- halt.
```

This closes Prolog.

## 🧪 Let's Experiment

Now that you have it working, let's try some variations to understand better.

### Experiment 1: What if you remove `nl`?

**Change your program to:**
```prolog
hello :- write('Hello, World!').
```

**Load and run it:**
```prolog
?- consult('hello.pl').
?- hello.
```

**What happens?**
```
Hello, World!true.
```

Notice that `true.` appears on the same line! That's because we didn't add a new line.

### Experiment 2: What if you add more text?

**Change your program to:**
```prolog
hello :- write('Hello, World!'), nl, write('How are you?'), nl.
```

**Load and run it:**
```prolog
?- consult('hello.pl').
?- hello.
```

**What happens?**
```
Hello, World!
How are you?
true.
```

See how the comma lets us do multiple things in order?

### Experiment 3: What if you misspell `write`?

**Change your program to:**
```prolog
hello :- wrrite('Hello, World!'), nl.
```

**Try to load it:**
```prolog
?- consult('hello.pl').
```

**What happens?**
```
true.
```

It loads fine! Prolog doesn't check if `wrrite` is a real function yet. But when you try to run it...

```prolog
?- hello.
```

**You get an error:**
```
ERROR: Undefined procedure: wrrite/1
```

This is Prolog saying "I don't know what `wrrite` is. Did you mean `write`?"

## 📋 Anatomy of a Prolog Program

Every Prolog program has this basic structure:

```prolog
% Comments (optional)
fact1.
fact2.

rule1 :- conditions.
rule2 :- condition1, condition2, condition3.

% Then you ask questions in the interpreter
?- query.
```

---

## 🎓 What You Just Learned

- **`%`** creates comments
- **`:-`** means "if" or "is defined as"
- **`write()`** prints text
- **Single quotes `'...'`** contain text
- **`,`** means "and" (do multiple things)
- **`nl`** prints a new line
- **`.`** ends a statement
- **`consult()`** loads a file
- **`true.`** means the query succeeded

---

## 🚨 Common Mistakes

### Mistake 1: Forgetting the period
```prolog
hello :- write('Hello, World!'), nl
% ERROR! Missing period at the end
```

### Mistake 2: Forgetting quotes around text
```prolog
hello :- write(Hello, World!), nl.
% ERROR! Text needs single quotes
```

### Mistake 3: Using `(` instead of `:`
```prolog
hello ( write('Hello, World!'), nl.
% ERROR! Should be :- not (
```

### Mistake 4: Capital letter in the rule name
```prolog
Hello :- write('Hello, World!'), nl.
% Problem! Rules should start with lowercase
% (We'll explain why later)
```
