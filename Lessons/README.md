## 🚀 Quick Start

### For Mac Users:
```bash
# Install Prolog
brew install swi-prolog

# Start learning
cd ~/Desktop/"Dann Folder"/MyProjects/Prolog
swipl
```

### For Windows Users:
1. Download SWI-Prolog from https://www.swi-prolog.org/download/stable
2. Run the installer
3. Open Command Prompt and type: `swipl`

## 📖 Lesson Details

### Lesson 0: Lesson Plan
**What to expect:** Course overview, structure, and goals
**Time:** 5 minutes
**Key points:** All lessons build on each other

### Lesson 1: Installation Guide
**What to expect:** Step-by-step installation for your OS
**Time:** 10-15 minutes
**Key points:** Don't skip this! You need Prolog installed to practice

### Lesson 2: What is Prolog
**What to expect:** Why Prolog is different from other languages
**Time:** 15-20 minutes
**Key points:** 
- Declarative vs Imperative
- Logic programming mindset
- Facts, Rules, Queries

### Lesson 3: Your First Program
**What to expect:** Write and run a working Prolog program
**Time:** 15-20 minutes
**Key points:**
- Understanding syntax
- Loading and running files

### Lesson 4: Facts and Rules ⭐⭐⭐
**What to expect:** The foundation of Prolog programming
**Time:** 30-40 minutes
**Key points:**
- Facts = database entries
- Rules = logical deductions
- Complete family database example
- Multiple practice queries

### Lesson 5: Queries
**What to expect:** How to ask Prolog questions
**Time:** 20-30 minutes
**Key points:**
- Yes/No queries
- Variable queries
- Multiple answers (using `;`)

### Lesson 6: Unification ⭐⭐⭐
**What to expect:** How Prolog actually matches patterns
**Time:** 25-35 minutes
**Key points:**
- Pattern matching mechanism
- Variable assignment
- Why variables only keep one value
- Tracing through unification

**This explains the magic behind Prolog!**

### Lesson 7: Lists

**Time:** 25-35 minutes
