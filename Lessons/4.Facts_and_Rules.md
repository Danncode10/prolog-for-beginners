# Lesson 4: Facts and Rules - The Foundation of Prolog

This is the most important lesson. **Facts and rules** are the foundation of everything in Prolog. Master this, and the rest becomes easy.

---

## 🏛️ Two Building Blocks of Prolog

### 1. Facts - "Things That Are True"

A **fact** is a simple statement about the world.

```prolog
parent(tom, bob).
parent(tom, liz).
parent(bob, ann).
color(apple, red).
color(sky, blue).
age(tom, 65).
```

**What does each mean?**
- `parent(tom, bob).` — "Tom is a parent of Bob"
- `parent(tom, liz).` — "Tom is a parent of Liz"
- `color(apple, red).` — "An apple is red"
- `age(tom, 65).` — "Tom's age is 65"

**Real-world analogy:**
Facts are like entries in a database. You're recording information about the world.

### 2. Rules - "Things We Can Figure Out"

A **rule** is a statement that says "if something is true, then something else is true."

```prolog
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).
```

**What does this mean?**
"X is a grandparent of Z IF X is a parent of Y AND Y is a parent of Z"

Let's break it down:
- `grandparent(X, Z)` — what we're trying to prove
- `:-` — IF
- `parent(X, Y)` — first condition
- `,` — AND
- `parent(Y, Z)` — second condition

**Real-world analogy:**
Rules are like logical deductions. "If A is true AND B is true, then C must be true."

## 🔬 Let's Create a Family Database

Let me show you a complete example that you'll actually run.

### Step 1: Create a New File

Create a file called `family.pl` with these facts:

```prolog
% Facts about who is a parent of whom
parent(tom, bob).
parent(tom, liz).
parent(bob, ann).
parent(bob, pat).
parent(pat, jim).

% Facts about who is a parent of whom (different family)
parent(mary, charlie).
parent(charlie, david).
```

**Save this file.**

### Step 2: Load and Test with Queries

Open Prolog:
```bash
swipl
?- consult('family.pl').
```

Now ask Prolog questions about the facts:

```prolog
?- parent(tom, bob).
```

**Answer:** `true.`

Prolog is saying: "Yes, according to the facts, Tom is a parent of Bob."

```prolog
?- parent(tom, X).
```

**Answer:**
```
X = bob ;
X = liz.
```

Prolog found both children of Tom! The `;` means "more answers available." Press `;` to see the next answer, or `.` to stop.

```prolog
?- parent(X, ann).
```

**Answer:** `X = bob.`

Prolog found that Bob is Ann's parent.

```prolog
?- parent(david, tom).
```

**Answer:** `false.`

This is not in the database, so Prolog says no.

## 📚 Now Let's Add Rules

Rules are where Prolog becomes powerful. Let's add rules to our family database.

**Add these lines to your `family.pl` file:**

```prolog
% Rule 1: X is a grandparent of Z if X is a parent of Y and Y is a parent of Z
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).

% Rule 2: X is a sibling of Y if they have the same parent
sibling(X, Y) :- parent(Z, X), parent(Z, Y), X \= Y.

% Rule 3: X is an ancestor of Y if X is a parent of Y OR X is a parent of someone who is an ancestor of Y
ancestor(X, Y) :- parent(X, Y).
ancestor(X, Y) :- parent(X, Z), ancestor(Z, Y).
```

**Now reload and test:**

```prolog
?- consult('family.pl').
```

### Test Grandparent Rule

```prolog
?- grandparent(tom, ann).
```

**Answer:** `true.`

**How did Prolog figure this out?**
1. You asked: "Is tom a grandparent of ann?"
2. Prolog looks at the rule: `grandparent(X, Z) :- parent(X, Y), parent(Y, Z).`
3. Prolog tries to find Y such that `parent(tom, Y)` AND `parent(Y, ann)`
4. Prolog finds: `parent(tom, bob)` is true AND `parent(bob, ann)` is true
5. So Y = bob, and the rule is satisfied!
6. Answer: `true.`

```prolog
?- grandparent(tom, X).
```

**Answer:**
```
X = ann ;
X = pat.
```

Prolog found all grandchildren of Tom by using the rule!

### Test Sibling Rule

```prolog
?- sibling(bob, liz).
```

**Answer:** `true.`

**Why?**
1. The rule says: `sibling(X, Y) :- parent(Z, X), parent(Z, Y), X \= Y.`
2. Prolog finds Z = tom where `parent(tom, bob)` AND `parent(tom, liz)` AND `bob \= liz` (they're different)
3. All conditions are true, so bob and liz are siblings!

The `\=` means "not equal to" — we need this so someone isn't their own sibling.

### Test Ancestor Rule

```prolog
?- ancestor(tom, jim).
```

**Answer:** `true.`

**Why?**
1. First condition of ancestor rule: `parent(tom, jim)` — false
2. Second condition: `parent(tom, Z), ancestor(Z, jim)`
3. Find Z: tom is parent of bob
4. Now check: is bob an ancestor of jim?
5. bob is not parent of jim directly
6. So check: is bob parent of someone who is ancestor of jim?
7. bob is parent of pat, is pat ancestor of jim?
8. pat is parent of jim, so YES!
9. This satisfies all conditions, so tom is ancestor of jim!

Notice: The ancestor rule calls **itself**. This is called **recursion** (we'll study this more later).

## 🎨 Understanding the Structure

### Facts vs Rules Side by Side

| **Fact** | **Rule** |
|----------|----------|
| `parent(tom, bob).` | `grandparent(X, Z) :- parent(X, Y), parent(Y, Z).` |
| A simple statement | A conditional statement |
| Always true if in database | True only if conditions are met |
| No body (nothing after `:-`) | Has body (after `:-`) |
| `fact_name(arguments).` | `rule_name(arguments) :- conditions.` |

## 🧠 How Prolog Reasons

When you ask a query, Prolog uses **logical reasoning**:

**Query:** `?- grandparent(tom, ann).`

**Prolog's thinking:**
```
1. Can I prove grandparent(tom, ann)?
2. According to rule: "grandparent(X, Z) :- parent(X, Y), parent(Y, Z)"
3. Can I prove parent(tom, Y) AND parent(Y, ann)?
4. Can I prove parent(tom, bob)? YES! (in database)
5. Can I prove parent(bob, ann)? YES! (in database)
6. So Y=bob works! Therefore grandparent(tom, ann) is TRUE!
```

## 📝 Writing Good Facts and Rules

### Rule 1: Names Should Be Descriptive

```prolog
% GOOD - Clear what it means
parent(tom, bob).
teacher(alice, student1).

% BAD - Unclear abbreviations
p(tom, bob).
t(alice, student1).
```

### Rule 2: Variables Start with Capital Letters

```prolog
% CORRECT
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).

% WRONG - Variables look like facts
grandparent(x, z) :- parent(x, y), parent(y, z).
```

In Prolog:
- **lowercase** = facts or constants
- **UPPERCASE** = variables (things we're looking for)

### Rule 3: Similar Facts Go Together

```prolog
% GOOD - Group by type
parent(tom, bob).
parent(tom, liz).
parent(bob, ann).

teacher(alice, class1).
teacher(bob, class2).
```

### Rule 4: Order Doesn't Matter (Usually)

```prolog
% These are the same
parent(tom, bob).
parent(mary, alice).

parent(mary, alice).
parent(tom, bob).
```

Prolog will find answers either way.

## 🎯 Complete Working Example

Here's a complete `family.pl` file you can copy and run:

```prolog
% ==== FACTS ====
% Parent relationships
parent(tom, bob).
parent(tom, liz).
parent(bob, ann).
parent(bob, pat).
parent(pat, jim).

% ==== RULES ====
% Rule: X is a grandparent of Z if X is a parent of Y and Y is a parent of Z
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).

% Rule: X is a sibling of Y if they share a parent
sibling(X, Y) :- parent(Z, X), parent(Z, Y), X \= Y.

% Rule: X is an ancestor of Y (recursive definition)
ancestor(X, Y) :- parent(X, Y).
ancestor(X, Y) :- parent(X, Z), ancestor(Z, Y).
```

**Commands to try:**
```prolog
?- parent(tom, bob).          % true
?- parent(tom, X).            % X = bob ; X = liz
?- grandparent(tom, ann).     % true
?- sibling(bob, liz).         % true
?- ancestor(tom, jim).        % true
```
