# Lesson 1: Installation Guide for Prolog

Welcome! Before we start learning Prolog, we need to get it running on your computer. Don't worry—it's free and easy.

---

## 🍎 Installation for macOS

### Step 1: Install Homebrew (if you don't have it)

Homebrew is a "package manager"—think of it like an app store for your terminal. It makes installing software super easy.

**Open your Terminal** (Command + Spacebar, type "Terminal", press Enter)

**Copy and paste this command:**
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Press Enter and wait. It'll ask for your password—type it in (you won't see the characters, but it's being typed).

Once done, it'll say something like "Installation successful!"

### Step 2: Install SWI-Prolog

Now that Homebrew is installed, installing Prolog is easy!

**In your Terminal, copy and paste:**
```bash
brew install swi-prolog
```

Press Enter and wait. It'll download and install Prolog automatically.

When it's done, you'll see a message like "SWI-Prolog was successfully installed!"

### Step 3: Test Your Installation

Let's make sure it worked!

**In your Terminal, type:**
```bash
swipl
```

You should see something like:
```
Welcome to SWI-Prolog (threaded, 64 bits, version 9.x.x)
?-
```

The `?-` is the **Prolog prompt**. It's waiting for you to ask it something!

**To exit, type:** `halt.` and press Enter.

✅ **Congratulations!** Prolog is installed on your Mac!

## 🪟 Installation for Windows

### Step 1: Download the Installer

Visit this website: https://www.swi-prolog.org/download/stable

**Look for the Windows section** and download the installer (usually something like `swipl-9.x.x.exe`)

### Step 2: Run the Installer

1. Find the `.exe` file you downloaded
2. Double-click it
3. Click "Next" through the installation wizard
4. Choose the default options (don't change anything unless you know what you're doing)
5. Click "Install" at the end
6. Wait for it to finish, then click "Finish"

### Step 3: Open Command Prompt

**Press:** Windows Key + R

**Type:** `cmd`

**Press:** Enter

You should see a black window with something like `C:\Users\YourName>`

### Step 4: Test Your Installation

**Type in the Command Prompt:**
```
swipl
```

**Press:** Enter

You should see:
```
Welcome to SWI-Prolog (threaded, 64 bits, version 9.x.x)
?-
```

If you see this, Prolog is installed! 

**To exit, type:** `halt.` and press Enter.

✅ **Congratulations!** Prolog is installed on your Windows machine!

## 🚀 How to Run Prolog Programs

Now that you have Prolog installed, here's how to work with it.

### Method 1: Interactive Mode (Best for Learning)

This is where you type commands and get immediate answers.

**In Terminal (Mac) or Command Prompt (Windows), type:**
```bash
swipl
```

Now you're in Prolog! The `?-` prompt means "Prolog is listening."

**You can now ask Prolog questions or run commands.**

To exit, type: `halt.`

### Method 2: Loading a File

When you create a Prolog program in a file (like `hello.pl`), you can load and run it.

**Assuming your file is on your Desktop:**

**On Mac:**
```bash
cd ~/Desktop
swipl hello.pl
```

**On Windows (Command Prompt):**
```
cd Desktop
swipl hello.pl
```

### Method 3: Load a File Inside Prolog

You can also start Prolog and load files from inside:

```bash
swipl
?- consult('C:/Users/YourName/Desktop/hello.pl').
```

(Or on Mac: `/Users/YourName/Desktop/hello.pl`)

## 🆘 Troubleshooting

**Problem:** I typed `swipl` and got "command not found"

**Solution (Mac):** 
```bash
brew install swi-prolog
```
And make sure the installation finished without errors.

**Solution (Windows):** 
Make sure you restarted your Command Prompt after installing. Close it completely and open a new one.

**Problem:** The installation is taking a long time

**Solution:** Be patient! It can take 5-10 minutes. Don't close the terminal.

**Problem:** I don't know how to navigate folders in Terminal**

**Tip:** `cd` means "change directory" (folder)
- `cd Desktop` takes you to Desktop
- `cd ..` takes you back one level
- `pwd` shows where you are right now
- `ls` (Mac) or `dir` (Windows) shows what's in the current folder
