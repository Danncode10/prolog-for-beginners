# Lesson 2: What is Prolog? (Why It's Different)

Welcome to the brain-bending part! Prolog is **nothing like** Python, JavaScript, or C++. Let me explain what makes it so special.

---

## 🧠 The Big Idea: Declarative vs. Imperative

### Normal Programming (Imperative) - "How to Do It"

Most programming languages are **imperative**—you tell the computer exactly what steps to take.

**Example in Python:**
```python
# How to find if John is a parent
people = [
    {"name": "John", "children": ["Alice", "Bob"]},
    {"name": "Mary", "children": ["Charlie"]}
]

for person in people:
    if person["name"] == "John":
        if len(person["children"]) > 0:
            print(f"{person['name']} is a parent")
```

You're saying:
1. Create a list
2. Loop through it
3. Check each person
4. If the name matches, check if they have kids
5. Print the result

### Prolog Programming (Declarative) - "What is True"

Prolog is **declarative**—you tell the computer what *facts* are true, and then ask it *questions*. The computer figures out the steps.

**Same example in Prolog:**
```prolog
% Facts: What is true
parent(john, alice).
parent(john, bob).
parent(mary, charlie).

% Query: Ask a question
?- parent(john, X).
```

You're saying:
1. "John is a parent of Alice" (fact)
2. "John is a parent of Bob" (fact)
3. "Mary is a parent of Charlie" (fact)
4. "Tell me who John is a parent of" (question)

Prolog will answer: `X = alice` and then `X = bob`

## 🔍 An Analogy: The Detective

Imagine a detective solving a case.

### Imperative Detective (Traditional Programming)
The detective has to **write down every step** they take:
- "I will walk to the desk"
- "I will open the drawer"
- "I will pick up the evidence"
- "I will put it on the table"
- "I will examine it"

### Declarative Detective (Prolog)
The detective just **tells the law what's true** and asks questions:

**Facts given:**
- "John was at the crime scene"
- "Mary was at the crime scene"
- "The weapon was found at the crime scene"
- "If someone was at the crime scene and the weapon was there, they could be suspicious"

**Question asked:**
- "Who could be the suspect?"

The law **figures out the logic automatically**. The detective doesn't have to say step-by-step what to do.

## 📚 Three Parts of Prolog

### 1. **Facts** - What is True

Facts are simple statements about the world.

```prolog
parent(tom, bob).
parent(tom, liz).
parent(bob, ann).
parent(bob, pat).
parent(pat, jim).
```

**Translation:**
- Tom is a parent of Bob
- Tom is a parent of Liz
- Bob is a parent of Ann
- Bob is a parent of Pat
- Pat is a parent of Jim

Facts are like **database entries**—you're recording what you know.

### 2. **Rules** - What We Can Deduce

Rules let you say "if something is true, then something else is true."

```prolog
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).
```

**Translation:**
- "X is a grandparent of Z **IF** X is a parent of Y **AND** Y is a parent of Z"

The `:-` symbol means "IF"
The `,` symbol means "AND"

So you're saying: "To prove X is a grandparent of Z, I need to show that X is a parent of someone, and that someone is a parent of Z."

### 3. **Queries** - What We Ask

Queries are questions you ask Prolog.

```prolog
?- parent(tom, X).
?- grandparent(tom, X).
?- parent(X, Y).
```

**Translations:**
- "Who is a child of Tom?"
- "Who is a grandchild of Tom?"
- "Tell me all parent-child relationships"

## ⚡ Why Prolog Is Cool

### 1. **Shorter Code**
For logic problems, Prolog programs are often 1/10th the size of equivalent programs in other languages.

### 2. **Built-in Search**
Prolog automatically searches for answers. You don't write loops.

### 3. **Perfect for Logic**
Problems involving relationships, rules, and constraints are natural in Prolog.

### 4. **AI Ancestor**
Prolog was used in early artificial intelligence research. It thinks like logic!

## 🎯 Where Is Prolog Used?

- **Artificial Intelligence** - Expert systems that reason about knowledge
- **Constraint Solving** - Scheduling, puzzle solving, optimization
- **Logic Programming** - Medical diagnosis systems
- **Natural Language** - Understanding human language
- **Database Queries** - Advanced searching and filtering

## 🤔 Real-World Example: Restaurant Recommendation

### The Traditional Way (Python-style thinking):
```
1. Get list of restaurants
2. For each restaurant:
   - Check if it has Italian food
   - Check if it's cheap
   - Check if it's open now
   - If all true, add to results
3. Return results
```

### The Prolog Way:
```prolog
% Facts
cuisine(ristorante, italian).
price(ristorante, expensive).
open(ristorante, yes).

cuisine(pizzeria, italian).
price(pizzeria, cheap).
open(pizzeria, yes).

% Rule: A restaurant is good IF it's Italian AND cheap
good_restaurant(X) :- cuisine(X, italian), price(X, cheap), open(X, yes).

% Query: Find me a good restaurant
?- good_restaurant(X).
```

Answer: `X = pizzeria`

Notice: **We didn't write HOW to search. Prolog figured it out automatically.**

```

┌─────────────────┐      ┌─────────────────┐
│  Instructions   │      │   Facts         │
│  ↓              │      │   ↓             │

(You tell it HOW)        (You tell it WHAT,
                          it figures out HOW)
```

## 🚨 Important: Prolog Thinks Differently

When you start learning Prolog, **stop thinking like a traditional programmer.**

❌ Don't think: "How do I loop through data?"
✅ Instead think: "What are the facts? What do I want to prove?"

❌ Don't think: "What steps do I need?"
✅ Instead think: "What rules define the answer?"

---

## 💡 Summary So Far

- **Prolog is declarative** - you state facts and rules, not steps
- **It uses logic** - facts, rules, and deduction
- **It searches automatically** - no loops needed
- **It's different** - requires a new way of thinking
