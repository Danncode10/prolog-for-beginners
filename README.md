# Prolog Learning Project 📚

A comprehensive, beginner-friendly Prolog learning course with step-by-step lessons, installation guides, and practical examples.

## 🎯 Project Goal

Learn Prolog from scratch with **detailed, classroom-style explanations** that don't assume prior knowledge. This project includes:

- ✅ Complete installation guides for Mac & Windows
- ✅ 7 comprehensive lessons covering core concepts
- ✅ Real-world examples (family relationships database)
- ✅ Hands-on practice problems
- ✅ Common mistakes and how to fix them

## 🚀 Quick Start

### For Mac:
```bash
# Install Prolog
brew install swi-prolog

# Navigate to project
cd "Desktop/Dann Folder/MyProjects/Prolog"

# Start learning
cd Lessons
# Open README.md in your editor
```

### For Windows:
1. Download SWI-Prolog from https://www.swi-prolog.org/download/stable
2. Run the installer
3. Open Command Prompt and navigate to your Prolog folder
4. Read `Lessons/README.md`

## 📖 How to Use This Course

1. **Start with:** `Lessons/README.md`
2. **Follow the lesson plan** in numerical order
3. **Type all examples yourself** (don't copy/paste)
4. **Experiment** with variations
5. **Complete challenges** at the end of each lesson

**Expected time:** 5-7 hours total (spread across your own pace)

## 🎓 What You'll Learn

After completing this course, you'll understand:

- ✅ What makes Prolog different from other programming languages
- ✅ How to write facts, rules, and queries
- ✅ How Prolog searches for solutions (unification & pattern matching)
- ✅ How to work with lists and recursive functions
- ✅ How to solve logic problems in Prolog
- ✅ How to debug and fix Prolog programs
